# python_utilities
Repository containing any Python modules or scripts that can be reused.

## Contents

- [`tp-link-deco/`](tp-link-deco/): `generate_hosts.py` syncs TP-Link Deco client hostnames into `/etc/hosts` for AdGuard Home. It keeps devices that are offline at run time, marking each with a "last seen" timestamp. See the [setup guide](tp-link-deco/adguard-server-installation-and-setup.md).
